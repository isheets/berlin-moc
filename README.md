# The mobility of care in Berlin

How well does public transport compete with the car on care trips: the trips to drop someone off,
pick them up, or buy the household's groceries? This project compares the two for households with
children in Berlin, with the commute as the benchmark, using the synthetic trips of MATSim Open
Berlin. It also asks what a bus or tram every 10 minutes would change.
